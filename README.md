## 🚀 À propos

Diplômé du titre professionnel **DWWM** (Développeur Web & Web Mobile), je me concentre sur
l'administration système, l'infrastructure auto-hébergée et l'automatisation.

Je développe des interfaces React et des backends PHP/Python, tout en gérant le cycle de vie
de l'infrastructure : déploiement Docker/Coolify, reverse proxies Caddy/Traefik, DNS local et
distant, sécurité Linux et scripts de maintenance.

- **OS principal** : Debian Linux 13 (Trixie)
- **Home Server** : Lenovo ThinkCentre M93p (`debian-homeserver`) — Caddy, dnsmasq,
  Home Assistant, Immich, Navidrome, Tailscale mesh
- **VPS** : Hostinger (`srvhostin`) — stack Docker, Coolify, Traefik
